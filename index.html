Software Design and Engineering

I improved the structure and modularity of the project by breaking it out into a clearly defined directory structure. Previously, the entire application was built from just two unstructured Python files. I refactored the layout into a modular design that includes separate folders for configuration (config/), data inputs (data/), assets (assets/), legacy code (old-code/), and source code (src/). The src/ folder contains the main logic, with separate files for CRUD operations (AnimalShelterCRUD.py), the DAO layer (AnimalShelterDAO.py), and the dashboard frontend (ProjectTwoDashboard.py).

This directory-level modularity makes the codebase easier to navigate, extend, and maintain — a major improvement over the original structure. It also follows best practices for professional repositories, separating concerns at both the file and folder levels.

Algorithms and Data Structures

I refactored the filtering logic for breed searches to use optimized regular expressions and conditional branching, improving performance and readability. The use of Python dictionaries and Pandas for dynamic data manipulation showcased my understanding of data structures, especially when transforming complex filters into fast, readable logic blocks. I also ensured the mapping logic used safe access patterns to avoid edge-case failures.
